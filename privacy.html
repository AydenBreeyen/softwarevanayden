Privacy.

Laatst bijgewerkt: 11 november 2026

Deze pagina legt uit wat er gebeurt wanneer je deze website bezoekt of contact opneemt met Software van Ayden.

Bezoek aan de website

De website gebruikt geen trackingcookies, advertentiepixels of analytische scripts. Lettertypen worden vanaf dezelfde website geladen. Er worden geen gegevens via een contactformulier verzameld.

Hosting via GitHub Pages

Deze website wordt gehost op GitHub Pages. GitHub kan technische gegevens, zoals je IP-adres, verwerken om de website te leveren en te beveiligen. Meer informatie staat in de privacyverklaring van GitHub.

Contact opnemen

Een e-maillink opent je eigen mailprogramma. Pas wanneer je zelf een bericht verstuurt, deel je je e-mailadres en de inhoud van je bericht. Die gegevens worden gebruikt om je vraag te beantwoorden en eventuele projectafspraken te maken. Neem geen gevoelige gegevens op die niet nodig zijn voor je vraag.

Vragen over je gegevens

Wil je weten welke contactgegevens er van je zijn, of wil je deze laten aanpassen of verwijderen? Stuur je verzoek naar contact@softwarevanayden.store.
